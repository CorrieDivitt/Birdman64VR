READ ME FIRST - Birdman64VR

Pilotwings 64 in VR, built on Birdman64 by NoahVl and its contributors.

PLAY IN VR: start your headset's OpenXR runtime first (Meta Quest Link
with Meta set as the active OpenXR runtime, or SteamVR), then
double-click "Start in VR.cmd". Birdman64VR.exe on its own starts the
normal flat game (as does "Start in VR.cmd" when no runtime is running).

ROM: Birdman64VR needs your own copy of the Pilotwings 64 (US) ROM: a
.z64, .n64 or .v64 file, or a .zip containing one. It cannot give you
one. Put the file next to Birdman64VR.exe and it is found automatically,
or choose it when the game asks. Only the US version works.

FIRST START: the game downloads the open-source code (about 1 MB) and
builds it on your PC. This usually takes under a minute; next time the
game starts right away. Keep the toolchain folder next to the exe.

CONTROLS IN VR: Touch controllers or a gamepad. Right stick press
recentres the view; left stick press (pad: View/Select) opens the
settings. R switches between chase and first person.

ON A MONITOR: move with W A S D. A = Space, B = Left Shift, Z = Z,
Start = Enter. C buttons (camera): I J K L. F11 toggles fullscreen.
Settings: Esc or F10.

YOUR SAVES: by default they live in %APPDATA%\Birdman64VR
(pw64.eep = progress, pw64.toml = settings, crash.log = bug reports)
and the build cache in %LOCALAPPDATA%\Birdman64VR\cache. Updating does
not lose them, and they are separate from Birdman64's. To keep
everything next to the exe instead, put an empty portable.txt file in
the exe's folder.

PROBLEMS: see README.md in this folder, and report bugs at
https://github.com/CorrieDivitt/Birdman64VR/issues (not to Birdman64).
